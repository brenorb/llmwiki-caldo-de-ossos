# Fontes brutas

Esta camada reúne registros de acesso e links para as fontes externas. Os registros são metadados de localização, incluindo o nível de acesso quando relevante. A interpretação editorial fica nas [notas de fonte](../index.md).

As cópias de trabalho e seu manifesto SHA-256 ficam no acervo local. Alguns registros trazem os hashes das versões consultadas. Ao incorporar outra versão, crie um novo registro e deixe a anterior rastreável.
